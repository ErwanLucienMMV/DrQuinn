# Dr_Quine

*42 — Cybersecurity*

An introduction to self-reproducing programs and Kleene's recursion
theorem. The project consists of three programs implemented in C and
x86-64 assembly, with a Python 3 implementation for the bonus. Each
program reproduces its source using an embedded representation, without
reading a source file or using `argc` / `argv`.

## Programs

| Program | Behavior |
| --- | --- |
| **Colleen** | Prints its own source to standard output. |
| **Grace** | Writes its own source into `Grace_kid.c` or `Grace_kid.s`. |
| **Sully** | Generates, compiles, and runs decreasing copies of itself. |

## Requirements

- Linux x86-64; tested on Fedora 44.
- A C compiler, GNU Make, and NASM.
- The standard C library.
- Python 3 for the bonus; no third-party packages are required.

On Fedora:

```sh
sudo dnf install gcc make nasm python3
```

## Build

```sh
make -C C
make -C ASM
```

Both directories provide the following rules:

| Rule | Description |
| --- | --- |
| `all` | Build the programs; rebuild only when needed. |
| `clean` | Remove object files and generated sources. |
| `fclean` | Run `clean` and remove executables. |
| `re` | Clean and rebuild everything. |

An individual program can also be built with `make -C C Colleen` or
`make -C ASM Grace`.

## Usage

Run each executable from its language directory. Generated files are
created in the current working directory.

### Colleen

The output must match the original source byte for byte. Both
implementations include a called helper and comments inside and outside
the entry point.

```sh
cd C
./Colleen > /tmp/Colleen.c
diff Colleen.c /tmp/Colleen.c
```

```sh
cd ASM
./Colleen > /tmp/Colleen.s
diff Colleen.s /tmp/Colleen.s
```

### Grace

Exactly three macros and one comment are used. The entry point is
generated by a macro, and the child source must match the original.

```sh
cd C
./Grace
diff Grace.c Grace_kid.c
```

```sh
cd ASM
./Grace
diff Grace.s Grace_kid.s
```

An empty `diff` output indicates identical files.

### Sully

The counter starts at `5`. The original creates and runs `Sully_5`, then
each descendant decrements the counter before producing the next source.
`Sully_0` runs and stops without creating a negative generation. A negative
initial counter produces no descendants.

```sh
cd C
./Sully
diff Sully.c Sully_0.c
diff Sully_3.c Sully_2.c
```

```sh
cd ASM
./Sully
diff Sully.s Sully_0.s
diff Sully_3.s Sully_2.s
```

The only source difference is the counter declaration. Each language
produces six sources and six executables, numbered `5` through `0`.
Assembly additionally produces six object files.

Sully requires `cc` in `PATH` at runtime; the assembly version also needs
`nasm`. Compiler or descendant execution failures propagate a nonzero
exit status.

## Python bonus

The `Python/` directory contains native Python quines. Source templates
use Python's `repr` and string interpolation; no C or assembly code is
called. Python 3 and its standard library are sufficient.

```sh
make -C Python
cd Python
python3 Colleen.py > /tmp/Colleen.py
diff Colleen.py /tmp/Colleen.py
python3 Grace.py
diff Grace.py Grace_kid.py
```

The Makefile provides `all`, `clean`, `fclean`, and `re`. It compiles the
original scripts into sibling `.pyc` files, which can also be run directly
with Python 3. These are incremental builds; source files are kept intact.

Python has no preprocessor macros. Grace uses three constants, one comment,
and a called function to reproduce the original macro-driven behavior.

## Implementation

The format string describes the program around a placeholder for its own
representation. Positional format arguments reproduce newlines, tabs,
quotes, and the format string itself.

Assembly sources use NASM's ELF64 format and the System V AMD64 calling
convention. Relative addressing and PLT calls support Fedora's default
PIE linking. The GNU stack note marks the stack as non-executable.

Output, file writes, file closing, and compiler execution are checked.
Errors return a nonzero
exit status. All source files must retain LF line endings for exact
reproduction.

The C layout follows the 42 Norm where compatible with the subject.
Exceptions are the encoded source strings, Colleen's required comment in
`main`, and Grace's required function-generating macros and single comment.
