# Dr_Quine

*42 — Cybersecurity*

An introduction to self-reproducing programs and Kleene's recursion
theorem. The project consists of three programs implemented in C and
x86-64 assembly. Each program reproduces its source using an embedded
representation, without reading a source file or using `argc` / `argv`.

## Programs

| Program | Behavior |
| --- | --- |
| **Colleen** | Prints its own source to standard output. |
| **Grace** | Writes its own source into `Grace_kid.c` or `Grace_kid.s`. |

## Requirements

- Linux x86-64; tested on Fedora 44.
- A C compiler, GNU Make, and NASM.
- The standard C library.

On Fedora:

```sh
sudo dnf install gcc make nasm
```

## Build

```sh
make -C C
make -C ASM
```

Both directories provide the following rules:

| Rule | Description |
| --- | --- |
| `all` | Build the programs; rebuild only when needed. |
| `clean` | Remove object files and generated sources. |
| `fclean` | Run `clean` and remove executables. |
| `re` | Clean and rebuild everything. |

An individual program can also be built with `make -C C Colleen` or
`make -C ASM Grace`.

## Usage

Run each executable from its language directory. Generated files are
created in the current working directory.

### Colleen

The output must match the original source byte for byte. Both
implementations include a called helper and comments inside and outside
the entry point.

```sh
cd C
./Colleen > /tmp/Colleen.c
diff Colleen.c /tmp/Colleen.c
```

```sh
cd ASM
./Colleen > /tmp/Colleen.s
diff Colleen.s /tmp/Colleen.s
```

### Grace

Exactly three macros and one comment are used. The entry point is
generated by a macro, and the child source must match the original.

```sh
cd C
./Grace
diff Grace.c Grace_kid.c
```

```sh
cd ASM
./Grace
diff Grace.s Grace_kid.s
```

An empty `diff` output indicates identical files.

## Implementation

The format string describes the program around a placeholder for its own
representation. Positional format arguments reproduce newlines, tabs,
quotes, and the format string itself.

Assembly sources use NASM's ELF64 format and the System V AMD64 calling
convention. Relative addressing and PLT calls support Fedora's default
PIE linking. The GNU stack note marks the stack as non-executable.

Output, file writes, and file closing are checked. Errors return a nonzero
exit status. All source files must retain LF line endings for exact
reproduction.

The C layout follows the 42 Norm where compatible with the subject.
Exceptions are the encoded source strings, Colleen's required comment in
`main`, and Grace's required function-generating macros and single comment.
